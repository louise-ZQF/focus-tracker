# focus-tracker

**专注时间管理工具 · 番茄钟 + 任务待办 + 日历 + 数据统计的一体化单页应用**

一个开箱即用的专注与时间管理工具：用番茄钟开启专注计时、管理任务与待办、通过日历回顾每日安排、查看专注统计，并进行阶段反思——全部在单个 HTML 文件中完成，无需安装、无需后端。

## 功能特性

- **专注计时**：番茄钟工作/休息循环，倒计时直观呈现
- **任务待办**：维护你的任务列表，专注期间聚焦当前任务
- **日历视图**：按日/周/月查看安排与历史专注记录
- **数据统计**：按日/月/年聚合专注时长，可视化你的时间投入
- **阶段反思**：记录反思笔记，回顾执行情况
- **链接管理**：收藏常用链接，工作流内直达
- **练习提交**：内置提交模块，适合课程/训练营场景

## 快速开始

直接双击 `index.html` 在浏览器打开即可使用，无需任何依赖。

## 技术栈

| 模块 | 说明 |
|---|---|
| 结构 | 纯 HTML5 单页 |
| 样式 | 原生 CSS 变量主题（多套柔和配色） |
| 数据 | 浏览器本地存储 |

## 设计说明

- 单文件架构：无构建、无依赖、可离线使用，便于分发与二次修改
- 主题色板：内置多组柔和配色（鼠尾草绿、湖蓝、薰衣草、玫瑰、蜜桃等），适配不同偏好
- 数据本地化：所有记录保存在浏览器本地，隐私友好
